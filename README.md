# Meu-primeiro-notebook
Neste desafio do curso de Data Science, fomos instigados a criar um notebook para ajudar o proprietário a escolher uma das 4 lojas que possui para se desfazer. 
Recebemos 4 arquivos CSV com os Dataframes das 4 lojas. 
O objetivo era fazer a análise de desempenho dos seguintes parâmetros:
- Análise do faturamento;
- Vendas por categoria;
- Média de avaliações das lojas;
- Produtos mais e menos vendidos;
- Frete medio por loja.

E ao final escolher a loja com menor desempenho.
Bibliotecas utilizadas:
- matplotlib.pyplot
- pandas
